### 第一部分：随机现象与基本概念

概率论研究的是**随机现象**。

#### 1. 随机现象与随机试验

| 概念           | 定义及特点                                        | 确定性现象对比                                                 |
| :----------- | :------------------------------------------- | :------------------------------------------------------ |
| **确定性现象**    | 在一定条件下，必然发生或必然不发生的现象。高等数学主要研究此类现象。           | *例:* 三角形内角和为180度。                                       |
| **随机现象**     | 在一定条件下，可能出现这个结果，也可能出现那样结果，且不能事先确定出现哪一个结果的现象。 | *例:* 抛一枚硬币，观察正面向上的次数。                                   |
| **随机试验 (E)** | 对随机现象的某一特征的试验或观察，简称试验。必须满足以下条件：              | (1) 试验可在相同条件下重复进行；(2) 试验前能确定所有可能结果；(3) 试验前不能确定将出现哪一个结果。 |

#### 2. 样本空间与随机事件

| 概念        | 符号               | 定义及解释                                       |
| :-------- | :--------------- | :------------------------------------------ |
| **样本点**   | $\omega$         | 随机试验的每一个可能结果。                               |
| **样本空间**  | $\Omega$         | 全体样本点组成的集合。它是研究随机现象的第一步。                    |
| **随机事件**  | $A, B, C, \dots$ | 试验结果具有某一特征，简称事件。**随机事件是样本空间 $\Omega$ 的子集**。 |
| **事件发生**  | $\omega \in A$   | 随机事件 $A$ 发生当且仅当随机事件 $A$ 所包含的某个样本点出现。        |
| **必然事件**  | $\Omega$         | 样本空间本身。每做一次试验总会发生。                          |
| **不可能事件** | $\emptyset$      | 空集。每做一次试验一定不发生。                             |

**【连接点】**：通过将随机事件定义为样本空间的子集，概率论成功地与**集合论**联系起来了。

#### 3. 事件之间的关系与运算

所有讨论都在同一个样本空间 $\Omega$ 上进行。

| 关系/运算     | 集合论语言                         | 概率论解释                                                                                                                               | 特殊情况                                                  |
| :-------- | :---------------------------- | :---------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------- |
| **包含**    | $A \subset B$ 或 $B \supset A$ | $A$ 发生必然导致 $B$ 发生。                                                                                                                  | $A=B$：若 $A \supset B$ 且 $B \supset A$。                |
| **交 (积)** | $A \cap B$ 或 $AB$             | $A$ 与 $B$ **同时发生**。                                                                                                                 | **互不相容/互斥:** $A \cap B = \emptyset$。                  |
| **并**     | $A \cup B$                    | $A$ 与 $B$ **至少有一个发生**。                                                                                                              | **和:** 若 $A_i$ 两两互斥，其并集记作 $\sum A_i$。                 |
| **对立事件**  | $\bar{A}$ 或 $A^c$             | $A$ 发生，且 $\bar{A}$ 不发生，或 $\bar{A}$ 发生且 $A$ 不发生。**$A$ 与 $\bar{A}$ 互斥 ($A \bar{A} = \emptyset$) 且其并集为必然事件 ($A + \bar{A} = \Omega$)**。 | $\bar{\Omega} = \emptyset, \bar{\emptyset} = \Omega$。 |
| **差**     | $A \setminus B$ 或 $A - B$     | $A$ 发生，且 $B$ 不发生。                                                                                                                   | **差化积:** $A - B = A \bar{B} = A \cap \bar{B}$。        |

**常用运算规律：**
*   **吸收律**
*   **幂等律**
*   **交换律**
*   **结合律**
*   **分配律**
*   **德莫根 (De Morgan) 定理:** $\overline{A \cup B} = \bar{A} \cap \bar{B}$ 且 $\overline{A \cap B} = \bar{A} \cup \bar{B}$。

### 第二部分：频率与概率的定义

#### 1. 频率与概率的统计定义

| 概念            | 公式             | 描述                                                   |
| :------------ | :------------- | :--------------------------------------------------- |
| **频率**        | $F_n(A) = m/n$ | 随机事件 $A$ 在 $n$ 次试验中发生的次数 $m$ 与总次数 $n$ 的比值。           |
| **频率稳定性**     | N/A            | 当试验次数 $n$ 逐渐增大时，频率总在某个常数附近摆动。这是概率论中的重要结论（第五章涉及大数定律）。 |
| **概率 (统计定义)** | $P(A)$         | 随机事件 $A$ 发生的可能性大小。$P(A)$ 是**频率的稳定值**。                |

#### 2. 古典概型（组合计数）

**古典概型**是满足以下两个性质的随机试验模型：
1.  样本点总数 $n$ 有限。
2.  每个样本点出现的概率相等。

**古典概率公式：**
设 $A$ 是事件，$m$ 是 $A$ 包含的样本点数，$n$ 是 $\Omega$ 的样本点总数。
$$P(A) = \frac{m}{n}$$

**基本性质：** $0 \le P(A) \le 1$， $P(\Omega) = 1$， $P(\emptyset) = 0$。

**计算工具：** 计算 $m$ 和 $n$ 时需要用到排列组合知识。
*   **乘法原理：** 完成某事件分 $k$ 步完成，总方法数是 $m_1 \times m_2 \times \dots \times m_k$。
*   **加法原理：** 完成某事件有 $k$ 类不同方法，总方法数是 $m_1 + m_2 + \dots + m_k$。
*   **排列 ($P_n^r$):** $n$ 个不同元素任取 $r$ 个排成一列的方法数。
*   **组合 ($C_n^r$):** $n$ 个不同元素取 $r$ 个为一组的方法数。
*   **重复排列:** $n$ 个不同元素每次取一个放回，取 $r$ 次，共有 $n^r$ 种取法。

#### 3. 几何概型

**几何概型**是古典概型的推广，样本空间放宽为无穷不可列个样本点。它满足：
1.  样本空间 $\Omega$ 是一个几何区域（区间、平面区域或空间区域）。
2.  等可能性：试验结果落在任一区域的可能性大小与该区域的**几何测度**（长度、面积或体积）成正比。

**几何概率公式：**
$$P(A) = \frac{\text{A 的几何测度}}{\Omega \text{ 的几何测度}}$$

#### 4. 概率的公理化定义与性质

**【连接点】**：古典概率和几何概率都满足某些基本性质。这些性质被推广为**概率的公理化定义**，这是现代概率论的基础。

**概率的公理化定义：** 设 $\Omega$ 是样本空间，对随机事件 $A$ 对应一个实数 $P(A)$，满足以下 3 条公理：
1.  **非负性：** 对任何事件 $A$, $P(A) \ge 0$。
2.  **规范性：** $P(\Omega) = 1$。
3.  **可列可加性：** 若事件 $A_1, A_2, A_3, \dots$ 两两互不相容，则 $P(\bigcup_{i=1}^{\infty} A_i) = \sum_{i=1}^{\infty} P(A_i)$。

**一般概率的性质 (由公理推导得出)：**
1.  $P(\emptyset) = 0$。
2.  **有限可加性：** 若 $A_1, \dots, A_n$ 两两互不相容，则 $P(\sum_{i=1}^{n} A_i) = \sum_{i=1}^{n} P(A_i)$。
3.  **对立事件概率：** $P(\bar{A}) = 1 - P(A)$。
4.  **单调性与差集：** 若 $A \subseteq B$，则 $P(B - A) = P(B) - P(A)$；推论： $P(A) \le P(B)$。
    *   **推广差集：** $P(B - A) = P(B) - P(AB)$。
5.  **加法公式：** $P(A \cup B) = P(A) + P(B) - P(AB)$。
    *   **推论：** $P(A \cup B) \le P(A) + P(B)$； $P(AB) \ge P(A) + P(B) - 1$。
    *   **三事件加法公式 (包含排斥原理)：**
        $$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(BC) - P(AC) + P(ABC)$$

### 第三部分：条件概率与独立性

#### 1. 条件概率与乘法公式

**条件概率 $P(B|A)$：**
在事件 $A$ 发生的情况下，事件 $B$ 发生的概率。
$$P(B|A) = \frac{P(AB)}{P(A)}, \quad \text{其中 } P(A) > 0$$

**性质：** 条件概率仍是概率，满足概率的公理化定义的三条基本性质。

**乘法公式：**
由条件概率公式导出，用于计算交事件的概率。
$$P(AB) = P(A) P(B|A) = P(B) P(A|B)$$

**多事件乘法公式：**
$$P(A_1 A_2 \dots A_n) = P(A_1) P(A_2|A_1) P(A_3|A_1 A_2) \dots P(A_n|A_1 A_2 \dots A_{n-1})$$

#### 2. 事件独立性

**【连接点】**：条件概率 $P(B|A)$ 描述了 $A$ 对 $B$ 发生的影响。若 $A$ 的发生不影响 $B$ 发生的概率（即 $P(B|A) = P(B)$），则事件 $A$ 与 $B$ 独立。

**两个事件的独立性：**
$A$ 和 $B$ 相互独立，等价于 $P(AB) = P(A) P(B)$。

**性质：**
若 $A, B$ 相互独立，则 $A$ 与 $\bar{B}$，$\bar{A}$ 与 $B$，以及 $\bar{A}$ 与 $\bar{B}$ 也相互独立。

**多个事件的独立性：**
$A_1, A_2, \dots, A_n$ 相互独立，要求对任意 $k$ 个事件的交集，其概率等于各自概率的乘积。
*   **注意：** 三个事件 $A, B, C$ **两两相互独立**（满足 $P(AB)=P(A)P(B)$ 等前三个条件）不能保证它们**相互独立**（即不一定满足 $P(ABC)=P(A)P(B)P(C)$）。

#### 3. 伯努利概型

**试验的独立性：** $n$ 次试验 $T_1, T_2, \dots, T_n$ 中，任何一次试验结果都不依赖于其他各次试验的结果，则称这 $n$ 次试验相互独立。

**伯努利概型 (n重伯努利试验)：**
指一个随机试验（观察事件 $A$ 发生与否，$P(A)=p, P(\bar{A})=q=1-p$）独立地重复进行 $n$ 次的模型。

**伯努利概率公式 (二项分布)：**
在 $n$ 重伯努利试验中事件 $A$ 发生 $k$ 次的概率 $P(B_k)$:
$$P(B_k) = C_n^k p^k q^{n-k}, \quad k = 0, 1, \dots, n$$
这与二项式定理 $(p+q)^n = \sum_{k=0}^n C_n^k p^k q^{n-k} = 1$ 相联系。

### 第四部分：全概率公式和贝叶斯公式

#### 1. 样本空间分割

**样本空间 $\Omega$ 的分割：**
$n$ 个事件 $A_1, A_2, \dots, A_n$ 满足：
1.  **两两互斥：** $A_i A_j = \emptyset$ ($i \ne j$) 且 $P(A_i) > 0$。
2.  **穷尽性：** $\sum_{i=1}^{n} A_i = \Omega$。

#### 2. 全概率公式

**【连接点】**：全概率公式是概率的**加法公式**和**乘法公式**的结合。

设 $A_1, A_2, \dots, A_n$ 为 $\Omega$ 的一个分割，$B$ 为任一事件，则事件 $B$ 的概率 $P(B)$ 为：
$$P(B) = \sum_{i=1}^{n} P(B A_i) = \sum_{i=1}^{n} P(A_i) P(B|A_i)$$

**内涵：** $P(B)$ 的“全”部概率被分解为许多小概率之和。通常将 $A_i$ 看作导致结果 $B$ 发生的**原因**。因此，**全概率公式是由原因推结果的公式**。

#### 3. 贝叶斯公式

**【连接点】**：贝叶斯公式利用全概率公式计算出在结果 $B$ 发生的情况下，该结果由某一特定原因 $A_i$ 导致的概率。

设 $A_1, A_2, \dots, A_n$ 为 $\Omega$ 的一个分割，$B$ 为任一事件 ($P(B)>0$)，则在 $B$ 发生的条件下，$A_i$ 发生的条件概率 $P(A_i|B)$ 为：
$$P(A_i|B) = \frac{P(A_i B)}{P(B)} = \frac{P(A_i) P(B|A_i)}{\sum_{j=1}^{n} P(A_j) P(B|A_j)}$$

**内涵：**
*   $P(A_i)$ 称为**先验概率** (prior probability)，是在没有进一步信息（不知道 $B$ 是否发生）的情况下，对 $A_i$ 发生可能性的认识。
*   $P(A_i|B)$ 称为**后验概率** (posterior probability)。当有了新的信息（知道 $B$ 发生）后，对 $A_i$ 发生的可能性大小有了新的估计。
*   **贝叶斯公式是由结果推原因的公式**。
