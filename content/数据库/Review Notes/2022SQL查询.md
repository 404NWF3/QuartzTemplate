
**1. 查询所有商品的编号、名称和库存量**

```sql
SELECT 商品编号, 名称, 库存量
FROM 商品;
```

**2. 查询库存量低于1000的商品的编号和名称**

```sql
SELECT 商品编号, 名称
FROM 商品
WHERE 库存量 < 1000;
```

**3. 查询菠菜和芹菜的单价**

```sql
SELECT 名称, 单价
FROM 商品
WHERE 名称 IN ('菠菜', '芹菜');
```

**4. 查询商品名称中含有“菜”和“肉”的商品的编号、名称和单价**

```sql
SELECT 商品编号, 名称, 单价
FROM 商品
WHERE 名称 LIKE '%菜%' OR 名称 LIKE '%肉%';
```

**5. 把“芹菜”的单价降低10%**

```sql

```

**6. 查询2022年11月订购的所有订单的编号、订购日期、客户姓名和送货地址**

```sql
SELECT 订单.订单编号, 订单.订购日期, 客户.姓名, 客户.送货地址
FROM 订单, 客户
WHERE 订单.客户编号 = 客户.客户编号
AND EXTRACT(YEAR FROM 订购日期) = 2022 AND EXTRACT(MONTH FROM 订购日期) = 11
```

**7. 查询所有商品的名称及总销售数量，总销售数量为0的也要显示**

```sql
SELECT 商品.名称, SUM(订单明细.销售数量) AS 总销售数量
FROM 商品 LEFT JOIN 订单明细 ON 商品.商品编号 = 订单明细.商品编号
GROUP BY 商品.商品编号, 商品.名称;
```

**12. 查询既没有订购过“水产海鲜”，也没有订购过“乳品烘培”类商品的客户编号和姓名**
*思路：先找出买过这两类的人，然后排除他们。*

```sql
SELECT 客户编号, 姓名
FROM 客户
WHERE 客户编号 NOT IN (
    SELECT DISTINCT 订单.客户编号
    FROM 订单, 订单明细, 商品, 类别
    WHERE 订单.订单编号 = 订单明细.订单编号
      AND 订单明细.商品编号 = 商品.商品编号
      AND 商品.类别编号 = 类别.类别编号
      AND 类别.类别名称 IN ('水产海鲜', '乳品烘培')
);
```

**13. 查询总销售金额排名前三的商品类别名称、总销售金额及排名**
*思路：先按类别分组求和并排名，再在外层过滤前三名。需要注意 `ORDER BY` 的位置。*

```sql
SELECT * FROM (
    SELECT 类别.类别名称,
           SUM(订单明细.销售数量 * 商品.单价) AS 总销售金额,
           RANK() OVER (ORDER BY SUM(订单明细.销售数量 * 商品.单价) DESC) AS 排名
    FROM 类别, 商品, 订单明细
    WHERE 类别.类别编号 = 商品.类别编号
      AND 商品.商品编号 = 订单明细.商品编号
    GROUP BY 类别.类别名称
) T
WHERE T.排名 <= 3;
```

**14. 查询购买过“蔬菜”类商品中所有商品的客户的编号和姓名**
*思路：使用计数法。客户买过的“蔬菜”种类数 = “蔬菜”商品的总种类数。*

```sql
SELECT 客户.客户编号, 客户.姓名
FROM 客户, 订单, 订单明细, 商品, 类别
WHERE 客户.客户编号 = 订单.客户编号
  AND 订单.订单编号 = 订单明细.订单编号
  AND 订单明细.商品编号 = 商品.商品编号
  AND 商品.类别编号 = 类别.类别编号
  AND 类别.类别名称 = '蔬菜'
GROUP BY 客户.客户编号, 客户.姓名
HAVING COUNT(DISTINCT 商品.商品编号) = (
    SELECT COUNT(*)
    FROM 商品, 类别
    WHERE 商品.类别编号 = 类别.类别编号
      AND 类别.类别名称 = '蔬菜'
);
```
