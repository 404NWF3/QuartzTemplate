# 实验五 SQL单表查询

## 实验信息
- **实验环境**: Oracle11g, Vscode Oracle SQL Developer
- **实验目的**:
    - 熟悉SQL*Plus的启动、退出和Oracle环境参数的设置方法；
    - 掌握对表的投影、选择操作；
    - 掌握简单和复杂查询条件的设置方法；
    - 掌握对查询结果进行排序的方法;
    - 掌握数据分类汇总方法。
